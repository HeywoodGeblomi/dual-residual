Compiler actually used: **g++ (Debian 14.2.0-19) 14.2.0**, flags
`-std=c++17 -O2 -Wall -Wextra`. Object files go in `obj/`, binaries in
`bin/` (no `build/` / `dist/` / `out/` / `target/`). A Makefile is here
for the same recipe; this box had no `make`, so g++ was invoked directly.

DS1 window keys are taken from `results/core_ds1_preds.csv` so they line
